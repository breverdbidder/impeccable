# reverse-api-engineer (vendored)

Unmodified copy of the `reverse-api-engineer` skill from https://github.com/kalil0321/reverse-api-engineer
(commit `e3aae749746f076f78f9642d83eeb3c7af9bac44`, package version 0.16.0), packaged as a Claude Code plugin so this
marketplace can serve it. MIT licence, see `LICENSE`.

The skill drives the `reverse-api-engineer` command-line tool, which it does not include. Install the tool once:

```bash
uv tool install reverse-api-engineer   # or: pipx install reverse-api-engineer
```

Agent mode also needs Node.js 20.19+. See `skills/reverse-api-engineer/references/setup.md`.
